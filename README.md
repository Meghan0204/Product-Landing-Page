# Product Landing Page

A responsive **product landing page** built with **HTML** and **CSS** as part of my web development portfolio. This project showcases layout, navigation, and design skills using basic front‑end technologies.

---

## Overview

This repository contains a static product landing page designed to display product information, navigation, and marketing content in a clean and responsive layout. It’s intended to demonstrate front‑end structure, styling, and organization for a simple business or product showcase.

---

## Features

✔ Header with navigation links  
✔ Hero section with branding image and title  
✔ Product content sections (features, pricing, etc.)  
✔ Responsive layout using CSS  
✔ Basic styling with custom stylesheets  

---

## Technologies Used

- **HTML5** – for page structure  
- **CSS3** – for layout, responsive design, and styling  

---

## How It Works

- The layout is defined in **`index.html`**
- Styles are defined in **`styles.css`**
- Images (such as the logo) are included in the project assets

The site structure follows a typical landing page flow, with sections such as header/navigation and main content areas.
